## Current project

### GeoAI Mineral Exploration

[Mining Geospatial Analytics](https://github.com/EHDataAI/mining-geospatial-analytics)

A progressive portfolio applying geospatial data science to mineral exploration.

The current work covers coordinate reference systems, geodesic calculations and the practical consequences of incorrect spatial transformations.

Completed public exercises:

- **LAB 01A - Coordinate Foundations**
- **LAB 01B - Cross-Zone CRS Analysis**
- **15 automated tests**

One of the current examples compares geodesic distance with projected calculations across UTM zones and shows how mixing coordinate systems can produce technically executable but scientifically invalid results.

Current roadmap:

Spatial EDA -> Spatial Cross-Validation -> Geochemical Analysis -> Mineral Prospectivity -> Explainability -> Uncertainty -> Remote Sensing
